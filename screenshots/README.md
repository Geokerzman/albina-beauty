## Охват

28 уникальных страниц основного домена: 26 содержательных, включая юридические, и два архива WordPress. Все найдены через ссылки и XML-карты сайта и вернули HTTP 200. Дополнительно снято текущее состояние связанного магазина: HTTP 404, “This store is unavailable”. Итого **58 основных PNG** плюс снимки интерактивных состояний.

Проверена также внешняя ссылка TerminSlot с десяти страниц услуг: в проверенной среде она возвращает **404 Not Found**. Состояние сохранено отдельно. Глобальная кнопка записи в шапке ведёт в WhatsApp.

Снимки сделаны после инициализации скриптов, загрузки шрифтов и прокрутки для lazy loading; галерея — после расчёта раскладки. Cookies отклонены через интерфейс. Карта на странице контактов поэтому показана с запросом согласия; это фактический вариант интерфейса. Содержимое и оформление сайта не изменялись, заявки не отправлялись.

Ширина полного PNG может превышать ширину окна при переполнении: это видно у мобильного прайса и политики конфиденциальности. Оригиналы сохранены без обрезки, чтобы зафиксировать проблему.

`audit/<id>.desktop.json` и `audit/<id>.mobile.json` содержат итоговые данные. Файлы `audit/<id>.json` без указания размера — первоначальный проход; он предшествовал полной инициализации динамических компонентов. Для актуального состояния используйте варианты с `.desktop` / `.mobile`.

Обход ограничен доступными публичными страницами целевого сайта, его sitemap и связанными точками магазина/записи. Социальные сети, все внешние правовые ссылки и бесконечные варианты поисковых запросов не являются отдельными страницами этого реестра. Административные и закрытые разделы не проверялись.
