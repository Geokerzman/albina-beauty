# Проверка первого этапа

- Production-сборка `npm run build` проходит; Next.js статически генерирует все 31 публичный маршрут.
- `npm run typecheck` и `npm run check:content` проходят.
- Проверено соответствие всем 28 URL исходного сайта, 13 услугам и 101 ценовой позиции.
- Выполнены 62 браузерные проверки: 31 страница на 1440 × 1000 и 390 × 844 px. HTTP 200, один H1 на странице, изображения загружены, горизонтального переполнения нет.
- Дополнительно проверены восемь основных страниц на 320, 768 и 1024 px: 24 проверки без горизонтального переполнения.
- Axe: девять основных шаблонов на двух ширинах, 18 аудитов без автоматически найденных нарушений. Это выборочная автоматическая проверка, а не полная сертификация доступности.
- Вручную проверены фильтры, поиск и пустое состояние каталога, поиск + категория прайса, выбранная позиция в записи, подготовка WhatsApp-ссылки, клавиатурные стрелки и Escape в галерее, диалоги команды, мобильное и десктопное меню.
- После финальной сборки проверены дата в форме, sitemap (200), robots (200) и неизвестный URL с собственным экраном 404 (404). Браузерных ошибок в этом завершающем проходе не обнаружено.
- Сообщения, заявки и бронирования не отправлялись; исходный сайт и боевой домен не изменялись.

Материалы: `screenshots/redesign/README.md`, `qa-results.json`, `responsive-results.json`, `verification-summary.json` и `production-smoke.json`. Скриншоты публичных страниц сняты с production-сборки.

CMS, хранение обращений и внешняя система бронирования в этот этап не входят. Согласование цен и обновление старых юридических текстов описаны в `CONTENT_DECISIONS.md` и плане разработки.
